Mini DnD Game Console Application

Gatus, Mefiel Ann T. | BSCS 3-2

This console application was inspired by the concept of the game Dungeons and Dragons. 

This game has features:
- D20 rolls
- NAT 1 / Critical Failure
- Roll Threshold 
- Random curse that can override success 
- 3 options per scene (Since it’s mini, no custom action can be done by the player)
- Scaling penalty (HP reduction proportionally ascend with the scene)

Since this is a text-based narrative RPG with dice mechanics, it’s a simplified, single-player console D&D one shot.

A player
- will encounter 3 scenes 
- can choose by the 3 options on what he thinks is best to do in each scenario
- have only one (1) lucky charm throughout the game
- can decide whether to use their (1) lucky charm to nullify the random curse or not
- can fail by not meeting the roll threshold or by random curse (lucky charm can only absorb the random curse and not the bad luck of not rolling greater than or equal to roll threshold).
- can succeed by picking the right choice, rolling higher than the threshold, and finishing the game with >0 remaining hp.
